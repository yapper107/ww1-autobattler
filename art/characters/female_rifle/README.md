# Female rifle prototype — approved grip C

User-authored project character and rifle: Tripo-generated meshes, refined matte
palette and rig in Blender. Animation source: the user's downloaded Mixamo Pro
Rifle Pack, retargeted and baked into this project's model. These are project assets,
not a standalone animation pack for redistribution.

`approved_grip_C.blend` preserves the approved editable setup. `SK_Female_Rifle.fbx`,
`SM_Rifle.fbx` and `A_*.fbx` are the portable import inputs. `manifest.json` records
clip timing, measured source pace, cycle alignment and palette colors. The source
inventory records original clip names and durations.

See [the integration guide](../../../docs/CHARACTER_ANIMATIONS.md) for rebuilding,
controls, selection logic, tests and remaining prototype limitations.
