# Bolt-action staff rifle — first multiview reference set

Generated 19 September 2026 with the built-in image generation tool, using the user-selected rifleman concept. These are exploratory image references, not a finalized 3D model or an approved art specification. No Tripo reconstruction has been tested yet.

Upload each PNG separately into the matching Tripo slot:

- Front: directly toward the crystal/muzzle.
- Left: rifle's physical left side; muzzle left, stock right; bolt handle on far side.
- Right: rifle's physical right side; stock left, muzzle right; bolt handle visible.
- Back: directly toward the buttplate.

All views keep the top of the weapon up. Front and back are enlarged to show thickness; pixel scale differs from the side views. The generated views approximate a shared design rather than mathematical projections from an existing mesh. Check proportions and occlusion in the reconstructed model.

Reference: female_rifleman_azure_concept_art.png, also saved in the repository as art/concepts/initial-examples/rifleman-v01.png.

Prompt direction: isolate the original rifle; orthographic views; simple flat low-poly brown wooden stock and shaft; charcoal bolt-action receiver, right-side bolt handle, trigger guard, two fore-end bands; slim angular wooden fork holding one slender cyan muzzle crystal. No character, magazine, scope, grain, fine hardware, labels, floor or bloom. Transparent background. The right profile established the design; other views used generated references to preserve it.
